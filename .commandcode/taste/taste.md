# Taste

- Prefers work be purely additive/preserving: never delete, remove, or destroy files, code, branches, data, migrations, existing functionality, or existing database tables/schema unless explicitly confirmed first. Always add/modify rather than replace existing work; when a new feature needs storage, prefer new tables over altering existing ones, and treat existing source tables as read-only. Confidence: 0.95
- When diagnosing an issue, reports the root-cause findings and proposed options to the user first before making any changes ("what is missing? first let me know"). Confidence: 0.8
