- Fix: migration `20260910000008_hold_overdue_lots_for_admin.sql` (applied) redefines `auction_expire_overdue` as a no-op. Lot now HOLDS at 0 until admin picks UNSOLD / +30s / +60s in the TIME'S UP dialog.
